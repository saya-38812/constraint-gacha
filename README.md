# 制約ガチャ

「誰に」「課題」をガチャで引いて、その人の困りごとを解決するアイデアを3分で考える発想トレーニングです。

**▶ 遊ぶ：https://idea-omega-six.vercel.app**

## 遊び方

1. ハンドルを回して、「誰に」「課題」のお題を引く
2. タイマーをスタートして、3分で解決策を考える
3. 思いついたことをメモに残す（お題と一緒に記録されます）

もっと頭をひねりたいときは「縛りカプセルも出す」をオンにすると、「画面なし」「1日1回しか開けない」などの縛りが加わります。気に入ったお題は「キープする」で固定したまま、残りだけ引き直せます。

## 特徴

- お題は「誰に」70個・「課題」61個・「縛り」33個。シャッフルバッグ方式で、一巡するまで同じお題は出ません
- 解決のしかたは自由。デザイン思考の「問題定義」と「アイデア創造」の練習向けです
- メモはブラウザの中（localStorage）だけに保存され、どこにも送信されません
- スマホ・ダークモード対応

## お題を増やすには

`index.html` の中の `BASE` に、文字列を1つ足すだけです。

```js
const BASE = {
  who:{label:"誰に",items:[
    "中学生","高校生", /* ← ここに "新しいお題" を足す */
```

## 技術

- HTML / CSS / JavaScript の1ファイル構成（ライブラリなし）
- フォント：Google Fonts（Dela Gothic One, Zen Maru Gothic）
- ホスティング：Vercel（`main` への push で自動デプロイ）
